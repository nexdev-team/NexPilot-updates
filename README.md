# NexPilot public updates

Public signed installable plugin downloads. No private development history, personal site connection or credential is published here.

The WordPress plugin checks this HTTPS channel without a GitHub account or access key:

https://nexdev-team.github.io/NexPilot-updates/

Use the installable plugin ZIP from Releases, not the GitHub source archive of this distribution repository. Each site creates its own AI connection. The public updater verifies the pinned Ed25519 signature, expiry, archive identity, version and SHA256 before installation.

The automation checks daily, renews only authenticated existing metadata when at most 48 hours remain and publishes a strict allowlist of static files to Pages. ZIP bytes cannot change during renewal. Signing credentials stay in a main-only encrypted environment, never in source or public artifacts. No WordPress site is contacted or changed by the workflow.

GPL-2.0-or-later. Single-site edition with internal review; native Codex verified. No WordPress.org or independent-audit certification is claimed.
