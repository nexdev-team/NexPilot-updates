NexPilot 1.3.5 Stable

ΕΝΗΜΕΡΩΣΗ
Για εγκαταστάσεις που χρησιμοποιούν το υπογεγραμμένο δημόσιο κανάλι,
άνοιξε WordPress → Πρόσθετα → NexPilot και επίλεξε «Update now» όταν
εμφανιστεί το 1.3.5. Τα αυτόματα updates ακολουθούν την υπάρχουσα
ρύθμιση του site. Έλεγξε την έκδοση πρώτα σε staging και κράτησε backup.

ΓΙΑ ΝΕΑ ΕΓΚΑΤΑΣΤΑΣΗ
Χρησιμοποίησε το nexdev-site-connector-1.3.5.zip από το επίσημο release.
Το ZIP περιέχει μόνο το plugin, χωρίς κλειδιά σύνδεσης ή υπογραφής.
WordPress single-site 6.6.5 ή νεότερο, PHP 8.1 ή νεότερη,
HTTPS και PHP Sodium. Οι υπογεγραμμένες ενημερώσεις χρειάζονται ZipArchive.

ΕΠΙΘΕΩΡΗΣΗ SITE
Στο WordPress → Εργαλεία → NexPilot → Connections, ενεργοποίησε
το Site inspection για τη συγκεκριμένη σύνδεση. Περιλαμβάνει τη
λίστα προσθέτων, τα Flatsome UX Blocks και αρχεία πηγαίου κώδικα
themes και plugins. Χορήγησε την πρόσβαση μόνο σε έμπιστη σύνδεση,
καθώς ο πηγαίος κώδικας μπορεί να περιέχει ευαίσθητες πληροφορίες.

Επίσημες εκδόσεις: https://github.com/nexdev-team/NexPilot-updates/releases
